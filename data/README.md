# data/

| Path | Content | In git? |
|---|---|---|
| `sample/sample_conll.txt` | 15 hand-annotated sentences in CoNLL-2003 format (columns: token, 2 unused, NER tag) | yes |
| `sample/sample_articles.txt` | 3 short, synthetic news-style articles for the extraction / visualisation demo | yes |
| `raw/` | **put CoNLL-2003 here** (`train.txt`, `valid.txt`, `test.txt`) | no (git-ignored) |

The sample sentences are illustrative and written for this project; they do not report real events.
CoNLL-2003 is derived from the Reuters Corpus, which has its own usage conditions, so it is not redistributed here.
See `docs/DATASET.md`.
