# outputs/

Generated by `python -m ner_news demo` on the **bundled 15-sentence sample** in `data/sample/`.

* `extraction/` - entities extracted from `sample_articles.txt` (CSV, JSON, displaCy HTML, charts)
* `visualizations/comparison.html` - the same articles annotated by every approach, side by side
* `evaluation_sample/` - metrics, error analysis and plots on `sample_conll.txt`

> **These numbers are a smoke test, not a benchmark.** The sample is tiny and was written by the
> project author together with the gazetteers, so the rule-based scores are optimistic.
> Run the evaluation on the real CoNLL-2003 test set (`docs/DATASET.md`) for meaningful results.
